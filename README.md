# MP3 切分小工具

把一段 MP3 按照声音之间的停顿，切成多个小文件。支持批量处理、查看进度、暂停、继续和停止。

## 下载工具

点击这里：[下载 v6 完整工具包（含新手教程）](mp3-splitter-web-v6-complete.zip?raw=true)。

## 怎么使用

1. 下载上面的 ZIP 压缩包。
2. 在下载的文件上点击鼠标右键，选择“全部解压缩”。请先解压，再使用。
3. 打开解压后的文件夹，双击 `start.bat`。如果电脑隐藏了文件后缀，它可能只显示为 `start`，类型是“Windows 批处理文件”。也可以用 Edge 或 Chrome 打开 `index.html`。
4. 点击选择 MP3 文件。第一次使用建议先试一个文件，设置先保持默认。
5. 点击“开始切分”，等待处理完成，再点击页面的下载按钮保存结果。
6. 解压下载的结果 ZIP，就能得到切好的音频。

更详细的逐步说明，请阅读工具包里的《宝妈小白使用教程.txt》。

## 使用前了解一下

- 当前切分依据是音频停顿，不是文字识别，不能保证每一段刚好是语义完整的一句话。音乐和背景杂音可能影响切分效果。
- MP3 在自己的浏览器中处理，当前工具没有上传音频的功能。
- 页面需要联网加载 MP3 编码和 ZIP 打包组件，因此使用时请保持联网。
- 此仓库提供下载版；下载后在自己的电脑上打开使用。
